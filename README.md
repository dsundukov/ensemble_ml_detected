## Как собрать
1. Скачайте все файлы этой папки (части, `manifest.json`, `join_parts.py`).
2. Выполните `python join_parts.py` — части проверяются по SHA-256 и склеиваются в исходные архивы.
3. Распакуйте: `unzip model_*.zip`, `unzip validation_*.zip`.

Полные контрольные суммы — в `manifest.json`.
